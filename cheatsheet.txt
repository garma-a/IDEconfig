KITTY TERMINAL SHORTCUTS

Ctrl+T / Ctrl+Y     New tab in the current directory
Alt+Shift+1..5      Switch to tab 1..5
Ctrl+W              Close the current tab
F11                 Toggle fullscreen

Ctrl+C              Copy selected text, otherwise send interrupt
Ctrl+Shift+C        Copy to clipboard
Ctrl+Shift+V        Paste from clipboard
Ctrl+V              Disabled in this configuration

Ctrl+Shift+F5       Reload Kitty configuration
kitty_help          Show this file

UBUNTU DESKTOP SHORTCUTS

Win+backtick        Workspace 1
Win+1               Workspace 2
Win+2               Workspace 3
Win+3               Workspace 4
Ctrl+Alt+T          Open Kitty
Caps Lock           Ctrl

SETUP AND VERIFICATION

bash setup.sh
bash setup.sh --check

See README.md and docs/SETUP.md in the repository for setup details.
