Full setup plan (Ubuntu GNOME amd64; run as your desktop user):
1. Install apt prerequisites, Kitty, clipboard tools, compilers and database CLIs.
2. Install official Chrome and set it as the default browser.
3. Install Neovim >=0.11.3, Node 24, Go 1.26, .NET 10 and Zig 0.15.2.
4. Install JetBrains Mono Nerd Font, Oh My Zsh, theme and shell plugins.
5. Back up conflicting dotfiles and link Kitty/Zsh/Neovim to this checkout.
6. Restore bundled custom skills for installed AI clients. Skip absent clients.
7. Restore lazy-lock.json plugins; wait for Mason tools and Treesitter parsers.
8. Apply GNOME preferences and remove conflicting workspace shortcuts.
   Super+grave -> 1; Super+1 -> 2; Super+2 -> 3; Super+3 -> 4.
   Four fixed workspaces; Ctrl+Alt+T launches Kitty; Caps Lock acts as Ctrl.
9. Verify required components. Failures return a nonzero exit.
The real run needs network and sudo. Account logins remain user actions.
